# revisions/ — 产品修改意见归档

这里存放**文字修改意见**，按产品分文件夹。这里的内容会上传 GitHub。

## 规矩

1. **只放文字意见**，不放图片、视频、产品原图。
2. 每个产品一个文件夹，用产品 ID 或型号命名，如 `wallpanel-3310/`。
3. 每次修改意见一个文件，命名：`YYYY-MM-DD-第N版反馈.md`。
4. 意见里引用生成物时，只写本地路径或回执哈希（如 `sha256:xxx`），**不写可公开访问的链接**，因为生成物本身不上传。
5. 复制 `_TEMPLATE.md` 开新反馈。

## 为什么这样设计

- GitHub 上只有"想法和决策历史"，没有素材本体；
- 以后查任何一个产品，能看到改了几次、每次改了什么、为什么改；
- AI（Hermes）下次生成前会读这个产品的历史意见，避免重复犯错。
